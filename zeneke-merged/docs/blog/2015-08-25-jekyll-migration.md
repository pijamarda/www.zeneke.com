# Update interno

**Date:** 2015-08-25
**Categories:** blog, update

Al final he decidido quitar la dependencia que tenía en AngularJS para el sistema de navegación y menús.
Le daba un feeling the single-page-application, pero era demasiado para las necesidades de la web.

He montado la web sobre la plataforma [Jekyll](http://jekyllrb.com) que me permite también utilizar el sistema de templates al que estoy acostumbrado en Django, pero sobre una web estática.
