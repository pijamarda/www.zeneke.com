# Piratas vs Ninjas

Game development project based on the board game "Quatro" with a Pirates vs Ninjas theme.

## Project Timeline

### May 13, 2013 - Beginnings

**Idea**

The project consists of developing a game for the Android platform (phones and tablets), based on the board game ["Quatro"](http://en.wikipedia.org/wiki/Quarto_(board_game)). But with a different, more pleasant and enjoyable theme.

### May 30, 2013 - Progress

**Game Design Document (GDD)**

We now have a small draft of the GDD with ideas more organized.

**First pre-alpha version**

We created a first "playable" version on the same computer. You only need to have [Java](http://java.com/en/download/index.jsp) installed.

The project can be downloaded and run on PC.

### September 7, 2013 - Summer Changes

**Multiple Library Changes**

We got serious with development and tested different libraries and APIs.

#### LIBGDX

After testing our first functional version in Java, our first choice was to use [LIBGDX](http://libgdx.badlogicgames.com) libraries.

Advantages:
- Written in Java, so we can use all previous development
- Without rewriting anything, the application can be deployed on PC, Android, iOS, Mac, etc.

#### Unity 3D

Since we weren't making progress on graphics, we decided to try [Unity 3D](http://unity3d.com).

This is not a playable version, but a prototype of the possibilities.

## Project Status

The project was completed in early 2014. Final screenshots and assets are available in the [blog post](/blog/2014-02-08-cerdigres.md).
